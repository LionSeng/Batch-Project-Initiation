# 批量立项文件生成器

一个**离线**的网页应用：填表 → 浏览器端直接生成 3 个 Excel 立项文件并打包下载，无需联网、无需服务器。

适用于每月月底批量申报执行额 / 立项时，把繁琐的手工填表变成「选 + 填」。

## 页面结构（数据持久化：localStorage + IndexedDB 镜像 + 可选同步文件）

数据默认存本机浏览器，键 `bpi_project_library_v1` 为**进行中项目库**，`bpi_archive_v1` 为**历史归档库**（仅 `dashboard.html` 使用）。每次改动会额外写入同源浏览器的 IndexedDB 镜像（`bpi_local_cache`），并可连接一个本地 JSON 同步文件实现跨设备持久化（见下文「多设备同步」）。

1. **`dashboard.html` —— 主页面（推荐日常使用）**：单页工作台，已把「看板总览」与「项目库维护」**合并为一页**（原「看板 / 项目库」两个标签已合并）：
   - **统一工作台（默认视图）**：上方指标卡 + 来源/客户汇总；下方按「看板」或「列表」展示所有进行中项目，每行左侧复选框即选中。顶部可「➕ 添加项目」「📦 归档选中」「🗑 删除选中」「合并选中项」「📎 上传识别」「🗂 同步」「导出/导入 JSON」，以及「去批量立项 (N)」——勾选项目后点它，会直接打开 `index.html` 并把选中项预填进去（**一次选择、一处入口**，不再有丢失选择的第二步）。
   - **历史项目库（独立视图）**：已归档项目，可恢复或永久删除。
   - 右上角**同步胶囊 `☁`** = 连接/查看本地多设备同步（见下）。
2. **`index.html` —— 批量立项文件生成器**：从 `dashboard.html` 点「去批量立项」会带入选中项目并预填；也可在其中点「从项目库导入…」手动勾选。检查后一键生成 3 个 xlsx 并打包下载。生成器是项目库的**消费者**，不回写项目库。
3. **`library.html` —— 项目库独立轻量页（遗留/可选）**：仅维护进行中项目，与 `dashboard.html` 共用同一份项目库数据。功能已被 `dashboard.html` 的统一工作台覆盖，保留作轻量备用。

## 多设备同步（本地文件，不依赖 GitHub / 不上传服务器）

旧版的「GitHub 云同步」已移除：它需要手动填写 Token、在 Netlify 上因跨域/鉴权容易失败、会把项目数据写进代码仓库（仓库若公开则金额/客户名泄露），且每次同步会触发重新部署。

现改为**本地文件同步 + 浏览器内自动镜像**：

- **顶部同步胶囊（最显眼处）**：页面右上角常驻一个 `☁ 已连接 / ☁ 未连接` 胶囊，点开就是同步面板。打开页面会自动重连上次连接的文件，无需每次手动找。
- **连接一次，永久自动保存**：点胶囊 →「📂 连接同步文件」选一个本地 JSON（需 Chrome / Edge 的 File System Access API）。连接后，**每一次新增 / 编辑 / 归档 / 删除都会自动写入该文件**（800ms 防抖），不再需要手动「导出备份」才能恢复。文件句柄用 IndexedDB 持久化，同浏览器跨会话自动生效。
- **浏览器内第二份备份（IndexedDB 镜像）**：哪怕你没连同步文件，每次改动也会在同源浏览器的 IndexedDB 里留一份镜像。万一 `localStorage` 被清，重新打开会自动从镜像恢复（仅限同一浏览器内，不跨浏览器）。
- **推荐工作流（真正换浏览器/电脑也不丢）**：把同步 JSON 放进 **百度网盘 / 企业微信微盘** 的同步文件夹；云盘自动把它同步到你的其他设备。在另一台设备用 **Chrome / Edge 打开 Netlify 的 https 页面**，点胶囊 →「📂 选择已有文件」选同一个文件即可，之后自动双向同步。
- **不支持自动同步的浏览器**（Firefox / Safari，或本地双击 `file://` 打开）：自动同步不可用，靠 IndexedDB 镜像 + 手动「📤 导出 / 📥 导入备份」兜底。
- 数据**不上传任何服务器、不需要 Token、不需要 GitHub**，隐私风险低。

> ⚠️ 关键：本地双击 `file://` 打开时，Chrome/Edge 的自动文件同步通常不可用，**请改用 Netlify 部署的 https 链接**打开（满足安全上下文），同步才能真正自动写入。

## 直接用法

推荐用 Chrome / Edge 打开 `dashboard.html`：
- 在统一工作台维护每月要立项的项目（客户、金额、起止、人天），可「➕ 添加项目」、行内编辑/删除/归档、导出/导入 JSON 备份、上传文件识别建项；
- 勾选要立项的项目（每行左侧复选框，或「全选当前」），点「去批量立项 (N)」即可直接打开生成器并预填这些项目；也可在生成器内「从项目库导入…」手动勾选。

`index.html` 内：
1. **① 固定信息**：公司归口字段已预填，可折叠，一般每月只改一次。
2. **② 每个项目**：点「+ 添加项目」加一行，或点「从项目库导入…」勾选项目载入。每行顶部选客户（自动带出编号/名称/简称，编号唯一只读），再填项目名称、起止日期、项目金额、预算金额、决算金额。预算占比自动算；决算金额留空 = 等于预算。
   - 注：**项目编号只在生成「API预算决算」时需要**（立项时还没有编号，故仅勾选该文件时才校验必填）。
3. **④ 预览**：点「预览」可展开所有要写入的字段，缺项标红，确认无误再生成。
4. **③ 生成并下载**：得到 `批量立项文件_时间戳.zip`，解压后是 3 个 xlsx，直接上传公司系统。

生成的 3 个文件：
- `API预算决算 - 2026.xlsx`（21 列，含预算成本率/税金/毛利公式）
- `批量立项目-销管-模板.xlsx`（7 列，预算金额 = 金额 × 占比、末行合计）
- `批量立项文件.xlsx`（26 列，客户性质/行业/产品类型等下拉校验、P1–P5 人天）

## 源码结构

- `template.html` + `gen.js` + `app.js` + `picker.js` + `customers.js` + `vendor/` → 内联进自包含的 `index.html`（生成器）
- `dashboard.html` + 内联逻辑 + `picker.js` + `customers.js` → 主页面（统一工作台：看板总览 + 项目库维护 + 历史库 + 本地同步 + 上传识别），单页，直接编辑即可，无需构建
- `library.html` + `library.js` → 项目库独立轻量页（遗留备用，功能已被 dashboard 统一工作台覆盖）
- `gen.js`：纯生成逻辑（与 DOM 解耦，可被 Node 单测）

## 重新构建（改了生成器源码后）

```bash
python build_html.py
```

会把 `template.html` + `gen.js` + `app.js` + `picker.js` + `customers.js` + `vendor/` 重新内联进单一 `index.html`。
`dashboard.html` / `library.html` 为独立页面，直接编辑其 HTML/JS 即可，无需构建。
更新客户列表时，重新用客户档案表生成 `customers.js` 再构建。

## 部署到 Netlify（静态站点）

本仓库是纯静态站点，`index.html` 已自包含（库已内联）；`dashboard.html`、`library.html` 与其同目录引用 `picker.js` / `library.js` / `customers.js`。

在 Netlify 中连接此 GitHub 仓库后：
- **Build command**：`python build_html.py`（从源码重建 `index.html`）
- **Publish directory**：`.`（仓库根目录）
- 分支：`main`

推送代码即自动触发 Netlify 重新部署。

> 注意：本地同步依赖浏览器的 File System Access API（Chrome / Edge 的 https 页面可用）。Netlify 上部署的页面满足 https 条件；本地 `file://` 双击打开时不支持自动同步，请用「导出 / 导入备份」。
